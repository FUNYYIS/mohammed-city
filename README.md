# مدينة محمد — Mohammed City

مشروع جديد ومستقل للعبة مغامرات ثلاثية الأبعاد مبنية مباشرة بـ TypeScript وVite وThree.js.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. استخدم الوضع الأفقي.

## التحقق

```bash
npm run test
npm run build
npm run audit
```

النسخة الحالية هي **المرحلة الرابعة — مغامرات المدينة**. تبدأ بالمهمة الأولى
«الهروب من المستودع»، ثم تفتح المهمات 2–5 بالترتيب: الدراجة المسروقة، سباق
الشوارع، المنزل المهجور، والكراج السري. تشمل النسخة خريطة مدينة، حوارات، حفظًا
واستئنافًا، دراجة وسيارتين قابلتين للفتح، ثلاثة سباقات، لغز رموز، وتجميع قطع
وإصلاح سيارة كلاسيكية. تظل مناطق المدينة الأربع ومبانيها قابلة للاستكشاف
وتُحمّل تفاصيلها والشخصيات المحدودة حسب القرب.

التحكم على الكمبيوتر:

- `WASD` للحركة أو القيادة.
- `Shift` للجري، و`Space` للقفز، و`C` للانحناء.
- `E` للتفاعل، و`F` لركوب السيارة أو الخروج منها.
- `M` لفتح خريطة المدينة.
- `Esc` للإيقاف المؤقت وإعادة المهمة عند الحاجة.

هذه نسخة لعب متكاملة للأنظمة وليست الجودة البصرية النهائية. جميع مجسمات
المدينة والمركبات الحالية إجرائية وخفيفة وقابلة للاستبدال بأصول GLB.
