# مدينة محمد — Mohammed City

مشروع جديد ومستقل للعبة مغامرات ثلاثية الأبعاد مبنية مباشرة بـ TypeScript وVite وThree.js.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. استخدم الوضع الأفقي.

## التحقق

```bash
npm run test
npm run build
npm run audit
```

النسخة الحالية هي **المرحلة الأولى فقط**: أساس الحركة والكاميرا والتصادم والتحكم وPWA داخل ساحة اختبار. ليست المدينة النهائية ولا الـVertical Slice.
