# مدينة محمد — Mohammed City

مشروع جديد ومستقل للعبة مغامرات ثلاثية الأبعاد مبنية مباشرة بـ TypeScript وVite وThree.js.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. استخدم الوضع الأفقي.

## التحقق

```bash
npm run test
npm run build
npm run audit
```

النسخة الحالية هي **المرحلة الثالثة — المدينة الأساسية**. تبدأ بالمهمة الأولى
«الهروب من المستودع»، وبعد إنهائها يفتح وضع استكشاف يضم حي محمد، الشارع
التجاري، منطقة المستودعات، ومنطقة الكراجات. بيت محمد والسوبرماركت والمستودع
والكراج قابلة للدخول، وتُحمّل مباني المناطق والشخصيات المحدودة حسب القرب.

التحكم على الكمبيوتر:

- `WASD` للحركة أو القيادة.
- `Shift` للجري، و`Space` للقفز، و`C` للانحناء.
- `E` للتفاعل، و`F` لركوب السيارة أو الخروج منها.
- `Esc` للإيقاف المؤقت وإعادة المهمة عند الحاجة.

هذه نسخة لعب متكاملة للأنظمة وليست الجودة البصرية النهائية. جميع مجسمات
المدينة الحالية إجرائية وخفيفة وقابلة للاستبدال بأصول GLB.
