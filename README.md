# مدينة محمد — Mohammed City

مشروع جديد ومستقل للعبة مغامرات ثلاثية الأبعاد مبنية مباشرة بـ TypeScript وVite وThree.js.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية. استخدم الوضع الأفقي.

## التحقق

```bash
npm run test
npm run build
npm run audit
```

النسخة الحالية هي **Vertical Slice للمرحلة الثانية** وتحتوي على المهمة الأولى
«الهروب من المستودع»: لوحة كهرباء، ثلاثة قواطع مرتبة، مولد، باب فعلي، شارع،
سيارة قابلة للقيادة، وكراج ينهي المهمة.

التحكم على الكمبيوتر:

- `WASD` للحركة أو القيادة.
- `Shift` للجري، و`Space` للقفز، و`C` للانحناء.
- `E` للتفاعل، و`F` لركوب السيارة أو الخروج منها.
- `Esc` للإيقاف المؤقت وإعادة المهمة عند الحاجة.

هذه نسخة لعب متكاملة للأنظمة وليست المدينة أو الجودة البصرية النهائية. جميع
مجسمات المرحلة الثانية الحالية إجرائية وخفيفة وقابلة للاستبدال بأصول GLB.
